Fecha de última modificación

22 de noviembre de 2026

Descargar todos los datasets (datasets.zip)

Los archivos CSV usan el punto y coma (;) como separador y la coma (,) como separador decimal, y están codificados en ISO-8859-1, salvo laliga_resultados2425.csv, que está en UTF-8. En cada apartado se muestran las primeras filas del archivo y el código para leerlo en R.

Mostrar código 
library(readr)
library(dplyr)
library(gt)

E.1 Alturas de los alumnos de un aula

Descargar aula1.csv

Alturas, en centímetros, de los 11 alumnos de un aula. Es el primer ejemplo de los capítulos 5 y 6.

Mostrar código 
df <- read_csv2("datos/aula1.csv",
                locale = locale(decimal_mark = ",", encoding = "ISO-8859-1"))

df |> 
  slice_head(n = 6) |> 
  gt() |>
  fmt_number(
    columns = where(is.numeric),
    decimals = 2,
    drop_trailing_zeros = TRUE,
    dec_mark = ",",
    sep_mark = ""
  ) |>
  tab_style(
    style = cell_fill(color = "#f7f7f7"),
    locations = cells_body(rows = seq(1, 6, 2))
  ) |>
  tab_options(
    table.font.size = px(14),
    data_row.padding = px(6)
  )

E.3 Análisis de producto terminado de la fabricación de camembert

Descargar camembert.csv · Descargar camembert.xlsx

Análisis de control de calidad del queso camembert de una quesería entre el 11 de enero y el 29 de diciembre de 2016: 211 fabricaciones analizadas en 200 días, con la fecha, el número de fabricación del día, el extracto seco total, la materia grasa, el pH, los cloruros y los coliformes. La versión Excel contiene los mismos datos y una tabla dinámica. Utilizado en los capítulos 12 y 17.

df <- read_csv2("datos/camembert.csv",

E.6 Datos de los pingüinos Palmer

Medidas de 344 pingüinos de tres especies del archipiélago Palmer (Antártida). En el libro se cargan con el paquete palmerpenguins, disponible para R y para Python, que hay que instalar la primera vez (capítulo 5). Desde R 4.5 el paquete datasets incluye también penguins, pero con nombres de columna más cortos (bill_len, flipper_len, body_mass…); el código del libro usa los de palmerpenguins (bill_length_mm, flipper_length_mm, body_mass_g…). Utilizado en los capítulos 5, 7, 8 y 11.

Ver https://allisonhorst.github.io/palmerpenguins/

Mostrar código 
library(palmerpenguins)

df <- penguins

df |>

E.7 Llenado de yogures: serie completa del turno

Descargar llenado_yogures.csv

Pesos simulados de los 9.600 envases de yogur de 150 g de un turno de 8 horas (1 de octubre de 2024, de 08:00 a 16:00, un envase cada 3 segundos), con la hora de envasado, el número de envase, el subgrupo de 5 envases consecutivos, la posición en el subgrupo y el peso en gramos. Tras la primera media hora sin incidentes, el turno incluye seis incidentes: deriva ascendente, sobrecorrección, alta variabilidad, deriva descendente, escalón en el cambio de turno y oscilación periódica. Utilizado en los capítulos 14 y 17.

df <- read_csv2("datos/llenado_yogures.csv",

df |>

E.9 Experimento de cuajado: diseño factorial 2²

Descargar experimento_cuajo.csv

Doce fabricaciones de un diseño factorial 2²: temperatura de cuajado (30 y 34 °C) por dosis de cuajo (20 y 30 ml/100 L), con 3 réplicas por combinación. La variable respuesta (rendimiento_esm_pct) es el coeficiente de recuperación ESM/MP: el extracto seco magro del queso por cada 100 kg de materia proteica de la leche puesta en cuba, en porcentaje. Utilizado en los capítulos 10 y 17.

Mostrar código 
df <- read_csv2("datos/experimento_cuajo.csv",
                locale = locale(decimal_mark = ",", encoding = "ISO-8859-1"))

df |> 
  gt() |>
  fmt_number(
    columns = where(is.numeric),
    decimals = 2,
    drop_trailing_zeros = TRUE,
    dec_mark = ",",
    sep_mark = ""
  ) |>
  tab_style(
    style = cell_fill(color = "#f7f7f7"),
    locations = cells_body(rows = seq(1, 12, 2))
  ) |>
  tab_options(
    table.font.size = px(14),
    data_row.padding = px(6)
