Este repositorio contiene los documentos publicados en el libro web [La mejora continua en la producción quesera. Análisis de datos industriales usando Excel, Python y R](https://juanriera.github.io/mejora-continua/)

El objetivo de este libro es facilitar a los alumnos y profesores de Formación Profesional las bases para el análisis de los datos técnicos que se manejan en la industria, y su aplicación a la mejora continua. Para ello se presentan algunos conceptos estadísticos básicos, y se explica el análisis exploratorio de los datos industriales mediante gráficos y análisis sencillos, utilizando la hoja de cálculo y los lenguajes informáticos R y Python. Se presentan como ejemplo dos aplicaciones de interés en la industria: el control del contenido efectivo y el análisis de la precisión de los laboratorios.

El contenido debe ser de utilidad para la Formación Profesional Superior, y concretamente para el Curso de especialización de Formación Profesional de Grado Superior en Tecnología y gestión quesera, que con la categoría de máster, se imparte opcionalmente en las escuelas de Formación Profesional a partir de la publicación del [Real Decreto 1092/2024, de 22 de octubre](https://www.boe.es/diario_boe/txt.php?id=BOE-A-2024-21708).

En este repositorio se encuentran los archivos HTML del sitio web, los datasets utilizados y los .qmd originales de la edición en Quarto (https://quarto.org/).
